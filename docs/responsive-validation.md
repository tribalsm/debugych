## Исправлено

- На 320 px кнопка гостевой загрузки выходила за границу карточки. Текст и ширина теперь ограничены доступным пространством.

- Длинное название проекта без пробелов растягивало страницу. Добавлен перенос названия и файловых подписей.
- Заголовок блока кода и кнопка копирования могут переноситься. На мобильных увеличены основные интерактивные области.
- Высота кода и diff ограничена также высотой окна. Горизонтальная прокрутка остаётся внутри блока, исходный текст не изменяется.
- Таблицы сравнения и истории получили доступные названия, клавиатурный фокус и подсказку о горизонтальной прокрутке.

Бизнес-логика, серверные условия применения патчей, AI Engine, gVisor и ресурсы персонажа не изменялись.

## Ограничения

- Проверены Chromium viewport и настоящее Windows/WebView2 приложение. Физические Android/iPhone, Safari, экранная клавиатура и изменение системного DPI не проверялись.
- Это целевая UI-регрессия. Backend, API E2E и исполнение gVisor заново не прогонялись, поскольку ядро не менялось.
- Сборка выдаёт существующее предупреждение о размере 3D-chunk более 500 kB. Ресурсы 3D не менялись.
- На маленьком экране длинное доказательство требует вертикальной прокрутки. Код, diff и таблицы имеют отдельную прокрутку, чтобы сохранить структуру данных.
- Remote Mode уже использует опубликованный frontend. Для включения новых стилей в автономные ресурсы Local Mode потребуется последующая перепаковка desktop-релиза.
- Ветка не объединена с основной.
