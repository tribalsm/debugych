# Восстановление доступа после смены IP

31 октября 2026 года основной адрес перенесён на **https://debugych.46-226-161-120.sslip.io:9443/**.

## Причина

VPS больше не использует 89.22.232.119. Старое имя `debugych.89-22-232-119.sslip.io` продолжало разрешаться именно в этот IP. Отказ подтверждён из Windows, WSL, домашнего роутера и независимым [GitHub Actions-прогоном](https://github.com/tribalsm/debugych/actions/runs/41218714702). Это сетевой отказ до ответа приложения, а не подтверждённый дефект AI Engine.

На действующем IP 46.226.161.120 тот же VPS доступен с проверкой ранее доверенного SSH host key. До изменения конфигурации backend и gVisor уже работали. Принудительное направление старого hostname на новый IP возвращало HTTP 200 с действительным сертификатом; это использовалось только для диагностики.

## Что изменено

- Добавлен отдельный nginx-vhost для нового имени, HTTPS остался на 9443.
- Получен отдельный сертификат Let's Encrypt `debugych-ip-20261031`, действующий до 29 января 2027 года. Выпуск и пробное продление выполнены через IPv4, без отключения TLS-проверки. Обычная первая попытка выпуска закончилась тайм-аутом получения сертификата от ACME; повтор через IPv4 успешен.
- Новый сертификат добавлен в точную allowlist существующего deploy-hook. Проверены синтаксис hook и его graceful reload nginx с новым `RENEWED_LINEAGE`.
- В приватной конфигурации установлен новый `DEBUGYCH_PUBLIC_ORIGIN`. Оба прежних имени оставлены точными aliases; wildcard Host/Origin не разрешены. Старые публичные ссылки с зашитым прежним IP всё равно недоступны, поскольку этот IP больше не принадлежит серверу.
- Пересоздан только `server-web` с прежним образом и томом аккаунтов. ID контейнеров API, worker, PostgreSQL, Redis, supervisor и runner не изменились.
- Выполнен graceful reload nginx. VPN на 443, другие сайты и Docker daemon не перезапускались.
- Обновлены ссылка README, текущие инструкции, примеры конфигурации, defaults будущих Desktop-пакетов и адреса live-smoke инструментов. Датированные исторические отчёты сохранены с явным уведомлением о переносе.

Резервная копия исходной приватной конфигурации хранится только на VPS в `/root/debugych-ip-repair-20261031`, с закрытыми правами. Секреты в репозиторий не включены.

Готовность AI-провайдера не выдаётся за новую успешную генерацию: платных AI-вызовов и новых тестовых заданий в этой проверке было 0. Патчи не применялись.

## Вход и Desktop

Откройте новый адрес и войдите прежним логином и паролем. Аккаунты, проекты и история на сервере сохранены. Cookie и сохранённые сессии привязаны к origin, поэтому новый адрес требует нового входа; сбрасывать пароль не нужно.

В уже установленном Desktop укажите новый URL в настройках подключения и войдите заново. Изменения defaults в исходниках относятся к будущей упаковке; уже установленный EXE и его настройки автоматически этим коммитом не обновляются. Новая Windows-сборка в рамках восстановления адреса не создавалась.

В имени sslip.io зашит IP. При следующей смене адреса повторный перенос потребуется снова. Собственный домен с управляемой A-записью позволит сохранить имя сайта при смене VPS, но его покупка и настройка не выполнялись.
