# Публичное демо Дебагыча

Опубликовано 28 октября 2026 года: https://debugych.89-22-232-119.nip.io:9443/.

Без ключа и регистрации доступны Dashboard, проект, требования, план, тесты, Gherkin, результаты, Bug Proof, diff, сохранённая проверка исправления и отчёт. Кнопка «Попробовать демо» на главной открывает этот проект. Старый URL `/auth/login` тоже перенаправляет в демо. Вход владельца сохранён отдельно: `/auth/login?owner=1`.

## Источник данных

`infra/server/public-demo.json` содержит разрешённый к публикации снимок единственного контрольного проекта `78167145-424b-48a8-b3f9-6eefa284f3c3` и 25 точных GET-маршрутов. В проекте простое отклонение арифметической операции: вместо сложения выполнялось вычитание. Контрольный pytest подтвердил отклонение, Bug Proof воспроизвёл его в gVisor, подготовленный минимальный diff прошёл 2/2 теста. Оригинальный проект не изменён.

Тесты и патч являются offline fixtures для проверки инфраструктуры. Демо не выдаёт их за новую AI-генерацию. Snapshot содержит реальные сохранённые результаты выполнения, а не симуляцию успешного запуска. Состояние backend сейчас и запуск новых задач демо не проверяет. Эта информация явно указана в баннере интерфейса.

## Ограничения доступа

- Анонимные запросы обслуживаются из фиксированного снимка, без обращения к backend и без серверного ключа.
- В демо нет токена, cookie владельца или новой привилегированной сессии.
- POST, PATCH, PUT и DELETE к API отклоняются с 403 до передачи в backend. В том числе генерация, AI-чат, загрузки, запуск тестов, проверка и применение патча.
- Неопубликованные проекты, исходные ZIP, API-документация и другие GET-маршруты закрыты с 404.
- Кнопки изменения и запуска отключены. Доступны навигация, раскрытие доказательств, вкладки, просмотр кода и сохранённых результатов.
- Сессии владельца и прямой Bearer-доступ Desktop сохраняют прежние права. Выключение `PUBLIC_DEMO_FILE` в server-web возвращает закрытый веб-доступ.
- Набор не обновляется автоматически. Публикация другого снимка требует отдельной проверки его содержимого; пользовательские проекты автоматически не раскрываются.

## Проверки

- `node --test tests/server/web-session.test.mjs`: 2 passed. Проверены прежние сессии владельца и запреты публичного режима. Анонимные запросы не вызывают тестовый upstream.
- TypeScript, lint и production build: PASS. Сохраняется прежнее предупреждение Vite о размере 3D chunk.
- Frontend unit tests: 8 passed (7 companion + 1 release).
- `tests/server/public-demo-smoke.cjs`: PASS на опубликованном HTTPS без ключа, входа и cookie. Проверены 10 сценариев, включая главную, открытие проекта с главной, Test Studio, Bug Proof, diff, Fix & Verify, отчёт, мобильный размер и старый URL входа.
- Прямые POST к autonomous, files, companion/ask, verify-fix и apply-fix: 5/5 получили 403. Чужой project ID и docs получили 404.
- Новых LLM-вызовов 0, новых исполнительных заданий 0, applied=false. Настоящий backend продолжает отвечать установленному Desktop-клиенту.
- Первая дополнительная проверка кнопки главной ожидала устаревший заголовок обзора и завершилась ошибкой обвязки. Ожидание обновлено по текущему компоненту; итоговый повтор прошёл. Журналы сохранены.

Headless-проверки не управляют пользовательским экраном и не доказывают работу native drag/minimize/restore. Изменения выполнялись в `release/debugych-server-1.0`; merge в main не выполнялся. Пересоздан только принадлежащий этому deployment контейнер server-web; API, worker, gVisor и чужие сервисы не перезапускались.
