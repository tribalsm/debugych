## 3. Покрытие TypeScript

Транспиляция esbuild создаёт контролируемую карту исходника; Istanbul сохраняет её и после выполнения переносит счётчики на оригинальные JS/TS/TSX. Проверяются идентичность исходника, допустимые файлы и границы строк. Недостоверные карты не получают статус original-source. Старые отчёты сохраняют прежнюю семантику.

В реальном gVisor rules.ts: выполнены строки 3, 4; строка 6 не выполнена; строка 1 с TypeScript-типом исключена. Ветви 1/2, строки суммарно 3/4. Отдельно React/TSX/CSS: 1/1 passed, coverage_kind=istanbul-original-source, main.tsx с исходной строкой 2. Runtime runsc и прежние лимиты.

## CI и независимая сеть

Текущий код публикуется отдельной веткой. Результат нового полного прогона находится в [checks](https://github.com/tribalsm/debugych/actions/workflows/ci.yml?query=branch%3Afeat%2Fproject-rag-ts-coverage), независимая read-only проверка трёх HTTPS-страниц из GitHub-hosted runner в [Independent public access](https://github.com/tribalsm/debugych/actions/workflows/public-access.yml). Артефакт public-access.json содержит статусы и отметки стандартной TLS-проверки, без credentials и содержимого проектов. Эти CI-результаты нужно читать отдельно от локальных чисел выше; незавершённое задание не считается прошедшим.

В конце проверки дополнительно исправлен cold-build fallback: недоступность публичного хранилища embedding-весов не мешает собрать приложение с текстовым поиском. Отсутствие сети и повреждение весов проверены offline; checksum guard не отключается.

## Оставшиеся ограничения

- Отдельный официальный документ организаторов отсутствует; матрица основана на доступном пользовательском ТЗ.
- Новая RAG-интеграция проверена на локальной embedding-модели и контрактном LLM-транспорте. Новый платный GPT-6 Luna прогон не проводился, историческая live-автономность не доказывает её для всех новых изменений.
- Индекс ограничен 160 фрагментами. Repair/patch stages могут упереться в прежний лимит полного контекста; ручная проверка честнее скрытого обрезания.
- Source-map coverage относится к загруженным инструментированным модулям, не гарантирует полноту требований. Недостоверная карта даёт явный fallback.
- Чужой GitHub-hosted pipeline с экспортированным CI package ещё не запускался; сам скачанный клиент ранее проверен через настоящий HTTPS/gVisor.
- Прямой URL остаётся с портом 9443, поскольку 443 занят сохранённым VPN. Доступность из каждой российской мобильной/корпоративной сети не подтверждена.
- Сохраняются предупреждение зависимости Starlette и предупреждение о размере отдельного Three.js chunk. Модель, риг, анимации, GLB и 3D-ветка не изменялись.

Следующий шаг после согласования этой ветки: финальная репетиция конкурсной демонстрации и отдельная разрешённая проверка live RAG workflow в рамках бюджета, без расширения функциональности.
