# Dispatch Quotes

R1. GET /quote принимает целый weight в граммах. Для веса от 1 до 1000 включительно цена 700 RUB; от 1001 до 5000 включительно — 1100 RUB.
R2. Нулевой, отрицательный вес и вес больше 5000 отклоняются HTTP 422.
R3. При priority=true к цене добавляются 300 RUB.
R4. При pickup=true вес до 200 граммов включительно обслуживается бесплатно. Надбавка priority применяется после скидки pickup.
