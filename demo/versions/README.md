# Контрольные версии (не входят в AI-контекст)

- `../sample-python-app/shop.py`: исходная buggy-версия, дефект R1 (`>` вместо `>=`).
- `correct/shop.py`: корректные включительные границы R1, R3, R4.
- `discount-boundary/shop.py`: дефект R3, скидка не действует при ровно 1000.
- `quantity-boundary/shop.py`: дефект R4, количество ровно 100 ошибочно отклоняется.

Независимый oracle `demo/control/test_oracle.py` проверяет исходную версию и намеренно находит дефект. `tests/unit/test_demo_versions.py` применяет независимые контрольные проверки к каждой доверенной версии, проверяя ожидаемую матрицу обнаружения. В основной UI подключён только исходный магазин и исправленная версия. Остальные — подготовленный benchmark, не выдуманные результаты AI.
